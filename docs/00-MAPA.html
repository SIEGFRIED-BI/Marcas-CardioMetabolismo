Actualizar un mes — el flujo feliz

# 1. dejar el IQVIA en Hub-Marcas-Inputs/_iqvia-master/YYYY-MM/ y sincronizar
py shared/sync-mujer-pm.py   py shared/sync-snc-pm.py   py shared/sync-dermato-pm.py
pwsh shared/build-all.ps1 -Month YYYY-MM -Lines cardio,ATB,OTC,respiratorio
# 2. venta interna / recetas / stock
py shared/merge-ventas-internas.py <planilla.xlsx>
py shared/merge-recetas-snc.py <pivot.xlsx>  # (el merge que corresponda)
py shared/merge-stock.py <pivot.xlsx>
# 3. recalcular derivados + verificar + publicar
py shared/recompute-mol-perf-aggregates.py
py shared/build-kpis.py   py shared/build-families-perf.py
py shared/sync-kpistrip-with-kpis-json.py
py shared/audit-full.py   # debe dar FAIL: 0
git add -A && git commit -m "Corte YYYY-MM" && git push
⚠ Nunca edites un número a mano en data.js / const D: corré el script. Nunca reemplaces el time-series entero (los merge agregan meses). El pre-commit hook bloquea si se pierde historia o si el audit falla — no uses --no-verify.
